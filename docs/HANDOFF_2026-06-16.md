## 1. What this app is

Bilingual (English + Telugu) agricultural land marketplace for Telangana / AP / Karnataka.
Two-sided: **sellers** list verified land, **buyers** browse, wishlist, book site visits.

**Stack:** Next.js 16 (App Router) · Tailwind CSS (custom `paddy-*` / `turmeric-*` palette) · Supabase (Postgres + RLS + Auth + Storage) · Resend email · Vercel hosting · Jest + Playwright tests.

## 4. What was shipped since the previous handoff (8 Jun 2026)

- Shareable, no-login 2-step form: contact + location → land details + doc/photo uploads.
- Submissions stored in `listing_submissions` table. Admin reviews in **Admin → Leads** tab.
- Status workflow: `new → contacted → converted → rejected`. Inline admin notes per lead.
- Nav "List your land" now links directly to `/list-your-land`.
- **DB migration applied in production:** `phase16_listing_submissions.sql`.
- Key files: `src/app/list-your-land/page.jsx`, `src/components/listing/ListingSubmissionForm.jsx`, `src/app/api/listing-submissions/route.js`, `src/app/api/listing-submissions/upload/route.js`.

### Lead → Listing provisioning (PR #36 · Phase 17)
- Admin Leads tab now has a **seller picker + "Provision Listing" button** on each lead card.
- Clicking Provision: picks a seller account, calls `POST /api/admin/listing-submissions/[id]/provision` → creates a `pending` `seller_properties` row pre-filled from lead data → sets `converted_listing_id` + `seller_id` on the lead.
- After provisioning, a "View property →" link appears on the card.
- **DB migration PENDING in production:** `phase17_lead_provision.sql` (adds `seller_id uuid` column to `listing_submissions`).
- Key files: `src/app/api/admin/listing-submissions/[id]/provision/route.js`, `src/app/api/admin/sellers/route.js`, `src/app/admin/AdminClient.jsx`.

### Bug fixes
- **RLS error on form submit:** switched listing-submissions API routes from anon client to `createAdminClient()` (service role bypasses RLS).
- **Spinner stuck on fetch error:** added `try/finally` to `handleSubmit` and `uploadFiles` in `ListingSubmissionForm.jsx`.

### Dependency / CI fixes
- `npm audit` was failing CI with 21 vulnerabilities (including 1 high `form-data`).
- Applied `npm audit fix` for safe fixes. Added `overrides` in `package.json`:
  - `"uuid": ">=11.1.1"` globally (patched ESM version)
  - `"exceljs": { "uuid": "^8.3.2" }` (exceljs needs CJS uuid@8; scoped override keeps both working)
  - `"js-yaml": ">=4.1.0"` (patches DoS advisory)
- Added `transformIgnorePatterns: ['node_modules/(?!(uuid)/)']` to `jest.config.cjs` so Jest can process uuid's ESM output.
- Result: 0 high/critical vulnerabilities; 2 moderate (exceljs/uuid — unfixable without breaking property import; CI uses `--audit-level=high` so these don't fail).
